# Crypto 数据版图速览

> 这是博客的第一篇非 Rust 文章,同时也是分类系统的测试文——它应该出现在 `crypto_map` 分类下,和 `rust_learn` 系列互不干扰。

## 数据的三个层级

做 crypto 研究,数据源大致分三层:

| 层级 | 内容 | 代表 |
|---|---|---|
| 行情层 | K线、订单簿、资金费率 | 交易所 API (OKX/Binance)、CCXT |
| 链上层 | 转账、合约调用、TVL、DEX 交易 | Dune、DeFiLlama、直接跑节点 |
| 叙事层 | 社交热度、KOL 观点、资金流向传闻 | Twitter/X、链上标签服务 |

## 一个付费原则

工具订阅的定价里,往往一大半是**自然语言包装层**的溢价:同样的链上数据,裸 SQL(Dune)和"AI 洞察报告"能差出一个数量级的价格。

原则:**只为数据和算力付费,不为别人替你读数据的服务付费**——读数据、建模型,应该是自己的核心能力,外包了这一层,研究就变成了转述。
